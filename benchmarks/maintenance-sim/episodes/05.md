# Episode 05 — policy extension boundary

Provide a semantic extension boundary for policies applied during normal
entity movement; its internal names and representation are idiomatic choices,
not a required private method. `register_policy` (`name`,`kind`) accepts the
deterministic `clamp10` kind, which applies `min(normalNextX,10)`. Names must be
unique; duplicate names or unknown kinds yield `invalid_value` atomically and
success emits `register:<name>`. `assign_policy` (`id`,`name`) checks missing
entity before unknown name, then emits `policy:<id>:<name>`. Only assigned live
entities carry policy. Snapshot v2 adds sorted policy `{name,kind}` registry
and optional entity policy; absent fields default empty. Save/load restores
registry and assignments. Preserve all earlier obligations.

The new v2 top-level key is `policies`, an array of exactly `{name,kind}` entries
sorted by ordinal name, with unique ID-shaped names and kind `clamp10` only.
It defaults to [] when importing an earlier v2 snapshot. An assigned entity has
one extra `policy` string field in live and snapshot output; absent means normal
movement. An imported assignment must refer to an imported policy, otherwise
`invalid_value`; names must be unique. An unassigned entity has no policy key.
Registering or assigning does not move an entity. During a tick compute checked
normal next x, then clamp; followers see post-policy mover positions, and their
own policy applies after calculating their simultaneous follower step.
Removal drops that entity's assignment but not the policy registry. All other
snapshot keys are unchanged until explicitly extended by a later requirement.

## Public example

Input: `{"version":1,"operations":[{"op":"spawn","id":"a","x":9,"velocity":3},{"op":"register_policy","name":"cap","kind":"clamp10"},{"op":"assign_policy","id":"a","name":"cap"},{"op":"tick","count":1}]}`

Output: `{"version":1,"state":{"tick":1,"entities":[{"id":"a","x":10,"velocity":3,"policy":"cap"}]},"effects":["spawn:a","register:cap","policy:a:cap","tick:1"],"errors":[],"snapshots":[]}`
