The recommended question is: **Does an explicit exhaustive-match convention, compared with an initially equivalent fallback convention, help a fixed Codex agent satisfy all new and retained obligations when F# domain states evolve, within the same resource allowance?** A useful null/adverse answer would limit the convention's claimed agent benefit. The study cannot be justified merely by F# being less studied.
