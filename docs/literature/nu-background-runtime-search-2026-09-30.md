C11 refines C03's overloaded persistence query. It improves the functional-structure coverage, but durable-memory results still occupy much of the page. Durable recovery and retention of historical functional versions are different capabilities; excluding a result from this cost branch is not a claim that durable state is irrelevant to every interactive application.

The useful synthesis is conditional: source abstraction can coexist with changed physical layout [4], and logical immutability can coexist with physical mutation [5]. Collection engineering [20], compressed graph snapshots [25], locality-aware moving GC [40], and persistence-aware amortized analysis [42] expose different mechanisms. Latency-oriented GC [60], compiler-supported HAMTs [64], reference counting [72], packed-layout compilation [98] and version-release protocols [100] require their own workload and resource accounting.
