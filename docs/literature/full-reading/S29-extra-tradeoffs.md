## Reconstruction

The input is a set of legal architectural configurations together with **already quantified quality attributes**. Configuration features encode component presence, type counts, bindings, binding-type counts and numerical parameters. The approach aggregates these features with quality metrics, uses principal component analysis (PCA) to expose variance and correlations, lets an architect select relevant targets, then learns decision trees that relate variable thresholds to qualities (article pp. 3–7). The method is conceptually agnostic about whether qualities come from simulation, measurements or analysis. This demonstration uses HaiQ, combining configuration generation with probabilistic model checking, rather than maintenance outcomes generated by coding agents.

The demonstration has two scenarios and five variants: two tele-assistance-service configurations, each with 3,750 samples and 79 variables, and three network-infection variants, each with 60,000 samples and 78/106/68 variables (Table 1). It varies service reliability/latency and architectural constraints, then checks whether the explanatory analyses reflect these modeled differences. These configuration rows are not independent human adoption decisions or independent applications.

PCA identifies dominant variation and correlated design/quality variables; trees identify useful thresholds. The tele-assistance tree's `MAX_TIMEOUTS` root matters for predicting reliability even though that variable is not dominant in the PCA plot. Thus variance explained and decision relevance are distinct even within the paper's own example. The result supports feasibility of explaining a quantified design space, with acknowledged modeling/data requirements; it does not compare prospectively frozen advice against unaided or simpler reviewers, or test improvement in their subsequent maintenance outcomes.

## Numerical and artifact limits

- **Percent reduction is not percent retained.** Table 2's information reduction uses `1 − relevant variables / dataset variables`, although the surrounding prose describes the percentage remaining. Its mean 71.62% reduction and 88.37% explained variance are descriptive properties of these encoded datasets, not reductions in human effort or gains in decision utility.
- **Published values do not fully reconcile.** Figure 7's displayed components sum to 77.11% for TAS V2 (69.59 + 7.52), while Table 2 gives 73.11%. Figure 9's network V3 components sum to 99.05% (98.69 + 0.36), while Table 2 gives 95.32%. Neither discrepancy is silently repaired; neither number is used to calibrate ALF.
- **Normalization changes the analysis.** Article p. 5 specifies columnwise min–max scaling, followed by centering. The released TAS script instead divides rows by their row sums and subtracts each normalized row minimum. The network script calculates such quantities but passes unnormalized feature columns to `prcomp(center = TRUE, scale = FALSE)`. These are material specification differences, not evidence that a particular version generated the reported figures.
- **Data dimensions reconcile, but variant settings differ.** Tab-separated file checks give 3,750 rows per TAS variant and 60,000 per network variant. Removing the sample ID and the script-excluded betweenness/component-metric columns gives Table 1's dimensions. The first TAS V2 record, however, sets AS3 failure/latency to .5/11 and MS5 to .02/5, whereas article p. 8 describes .4/7 and .05/10. This bounded parameter check is not a reconstruction of the generator or the reported results.
- **The released plotting and tree settings also need reconciliation.** Scripts select displayed variables with `abs(PC1 correlation) > .4 OR abs(PC2 correlation) > .4`, which is not the stated geometric criterion of lying between the 50% and 100% ellipses. The TAS tree explicitly sets `minsplit = 2`, although the article says default tree parameters. The scripts contain no explicit separate pruning step or held-out decision-quality comparison. Both tree formulas exclude the other QoS columns from their predictors; do not accuse them of predicting one quality from the others.
- **An interpretable model still requires an information boundary.** Qualities are available for configurations before explanation. In ALF, collecting future candidate maintenance outcomes would consume resources and expose evaluation information; such a table cannot be treated as free adoption-time advice. Redundant structural encodings and choice of normalization also affect PCA influence, which does not establish a causal responsibility mechanism.

## Consequences and follow-up

**Retain** architectural tradeoff explanation as established prior art. **Narrow** ALF's contribution to incremental, prospectively evaluated maintenance choice value under an explicit information boundary. **Reject** variance explained, visual clarity, or model sensitivity as stand-ins for behavioral advice benefit. A simpler review using the same information and effort remains a necessary rival for a method-specific claim.

The accessible 2021 conference precursor (`10.1007/978-3-030-86044-8_4`) is an earlier PCA-centered version; it is not another completed reading or independent replication. Its edition-specific methods can be reopened if the journal extension leaves a relevant dependency. The journal's statement that architectural evaluation under uncertainty was reviewed by Sobhy et al. is a lead, not field-wide absence evidence.

Forward Scite screening exposes more direct human-value evidence: **S30**, *Supporting Early Architectural Decision-Making through Tradeoff Analysis: A Study with Volvo Cars*, and **S31**, *Supporting the Exploration of Quality Attribute Tradeoffs in Large Design Spaces*. **S32**, *The Architect in the Maze*, addresses whether generic ML explanations answer architects' questions. These are promoted rather than preserving a broad claim that architectural explanation lacks practitioner evaluation. **S33**, ADEPT, is a newer pattern-performance sensitivity method that may further narrow architectural-information firstness; its body remains pending access.

**Uniqueness is unconfirmed; decision value remains an empirical question; the ALF methodology remains proposed and unvalidated.** This reading changes the controls and information claim without authorizing experiments.
