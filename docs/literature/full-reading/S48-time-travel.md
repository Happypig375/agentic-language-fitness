## Mechanisms and boundaries

The paper gives local control of time domains, direction, step and synchronization in Dunai/Yampa. Transforming elapsed-time values changes a component's simulated speed without necessarily changing its sampling frequency (pp. 107–108). Ordinary switching forgets its predecessor; reversible switching retains it. Delay reversal requires history, while reversing external input requires recorded values rather than current input (pp. 109–110).

Three operations must remain distinct: reversing a computation, caching sampled values with interpolation, and restoring a saved signal-function continuation. Unbounded history can leak memory; a bound measured only in seconds still permits many samples when steps shrink. The more general cache policy can constrain sample count or drop intermediate samples. A checkpoint retains at most one prior signal function, which is not a proof that an arbitrarily large retained closure occupies fixed bytes.

The coordination example freezes discrete game progression while continuous animation catches up; the visual layer controls whether the conceptual model advances (p. 112). Other examples deliberately pause only movement while still processing collisions and input. Selective reversal leaves some changes irreversible. Therefore neither a zero time delta nor a restored local component means every subsystem or external effect has been rolled back.

The experience section uses two author-developed games, Lightsmash and Pang-a-lambda (pp. 113–115). It demonstrates composition and selected time-control behavior; there is no controlled maintenance/debugging study or task-outcome distribution. Figure 4 illustrates unbounded/bounded cache memory behavior with different time windows and scales, not a calibrated cross-engine cost comparison. Section 8 explicitly distinguishes exact recorded replay in S46 from reversal that can diverge through numerical rounding. Formal semantics for these time-manipulation constructs and stronger static leak guarantees remain future work (p. 116).

Rendered listings also require care before implementation reuse. The interpolation fraction is printed as `(t - t1) / t2 - t1`, rather than division by the time interval; the reversible bouncing example calls the earlier non-reversible function recursively; and the self-clocking prose and `lastStep` example give opposite Boolean descriptions. These are publication-level inconsistencies, not demonstrated defects in the released implementation. This reading does not silently repair or execute them.
