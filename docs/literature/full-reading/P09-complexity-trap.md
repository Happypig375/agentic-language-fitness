## Conditions and units

The study compares context policies within an issue-resolution trajectory, not different repository architectures or inherited predecessor generations. Main evaluation uses SWE-agent on 500 SWE-bench Verified instances, with five model configurations: Qwen3-32B thinking/nonthinking, Qwen3-Coder-480B FP8, Gemini-2.5-Flash thinking/nonthinking. Main model temperature .8; summary temperature zero; Gemini thinking ceiling 800 tokens, nonthinking zero. Main turn ceiling is 250. Model/scaffold configuration, source access and editable state are held within each comparison, but the generated trajectory can diverge after intervention (pp. 4-6).

Raw keeps system/user plus all reasoning, actions and observations. Masking preserves system/user and **all reasoning/actions**, replacing observations older than M=10 with placeholders. It is age-based, not an assessment of whether information is stale or resolved. Summary waits for N+M turns, summarizes N=21 plus the previous summary, retains ten recent full turns, and preserves system/user. This changes more than observation fidelity: old reasoning/actions are compressed too. Hybrid first summarizes unmasked history with N=43/M=10, then masks with W=10 during accumulation (equations 1-6; appendix E's exact prompt asks for user commitments, completed/pending work, code, tests, dependencies and version state).

M/N were selected using GPT-4.1-mini on a 150-instance Verified subset; this subset is not a held-out sample from the subsequent full 500. Preliminary Lite-50 experiments use three runs (150 trajectories), M=5 and a mean-token simulation for extended turns (pp. 16-20). They motivate the 250-turn ceiling, not an empirically verified provider window limit. Approximate 84% observation-token share is from that preliminary setting. OpenHands v0.43.0 uses a 50-instance probe; M=10 performs poorly, and M=58 is tuned for the different retry/history representation. Hybrid is likewise reported on Verified-50. These are limited scaffold/policy extensions, not universal constants.

## Results and negative evidence

Table 1: Qwen-Coder masking solves 274/500 (54.8%) versus raw 267/500 (53.4%) and summary 269/500 (53.8%). The 1.4-point raw/masking difference is **2.62% relative**, not 2.6 percentage points. Mean reported costs $1.29/$0.61/$0.64 imply 52.71% masking savings and $15 difference versus summary across 500, using rounded cells. Summary is cheapest for Qwen-32B nonthinking ($.50 versus masking $.55); Qwen-32B thinking has only about 10% masking savings and essentially none from summary. Short trajectories often finish before a summary triggers (pp. 7-9, 14-16).

Crucially, **Gemini thinking loses accuracy**: raw 40.4%, masking 36.4%, summary 31.4%. Paired 10,000-resample bootstrap intervals are -4.0 points [-7.8,-.2] and -9.0 [-13.0,-5.2], both marked significant (table 4). Thus the conclusion's universal >50% savings without significant performance loss is not supported by its own full table. Nonsignificant differences elsewhere do not establish equivalence, and raw-comparison tests are not direct masking/summary equivalence tests. Instance pairing handles shared tasks, but there is no repeated-seed main uncertainty or repository-cluster generalization analysis.

Longer summary trajectories are observed, but the proposed mechanism that summaries hide failure/encourage continuation is interpretive rather than a randomized mechanism ablation (pp. 7-8). Gemini's printed 52 versus 44 turns is an 18.18% increase, despite the prose's 15%; raw means are rounded and figure 4 does not recover exact underlying values. The critic-summary intervention adds a different prompt, guidance and cost; it does not reliably improve solve rate and is not a pure memory-size contrast (appendix D.3).

Hybrid claims 7%/11% savings and 2.6-point gain over raw, but compares a reported 50-instance hybrid with main baselines plotted at their 500-instance rates. A single 50-task binary trial cannot yield a 2.6-point paired difference. The release inspection below confirms the different sample sizes; a common-subset comparison is needed before treating the headline as a matched effect. The naive N=21 hybrid is more expensive, reinforcing sensitivity to policy choices (figure 5).

## Artifact and accounting inspection

[JetBrains-Research/the-complexity-trap](https://github.com/JetBrains-Research/the-complexity-trap/tree/bf15b5fb7d279679035a007ac9a81084d6b9a89a), commit `bf15b5fb7d279679035a007ac9a81084d6b9a89a`, was inspected read-only: README, hybrid YAML, `LastNObservations` and `SummarizeEveryNTurns` in `sweagent/agent/history_processors.py`, pricing portions of `notebooks/posthoc_compute_qwen_costs.py`, and the released per-instance CSV. README declares MIT and links full trajectories on Hugging Face; those trajectory archives were not downloaded or executed. OpenHands base commit is `fd3b4ac8e6db3103a3f8b488d44dd36e51e057be`; the precise modified fork was not inspected. No author code or model-backed reproduction ran.

The masking implementation counts observation messages, protects the first instance prompt and supports always-keep/remove tags. The summarizer recognizes assistant/tool pairs and preserves previous summaries internally. The hybrid YAML runs summarization before masking, confirming unmasked inputs to the summarizer. Its operational trigger should be tested with an explicit trace if reused, including tags, error/retry turns and cache invalidation.

Original read-only CSV aggregation found main groups with 496-500 rows, while pass numerators match the paper's fixed 500 denominator. Both hybrid groups have 50 unique IDs (N=21:27 passes; N=43:28). The CSV `cost` excludes separate `summary_cost`; summing only `cost` would understate the summary treatment. The paper's claim of 500 *common* paired instances therefore needs its missing-row merge/imputation policy reconciled with this released table. We did not infer zero cost for missing data or reproduce p-values.

The final [portable audit](artifact_csv_check.py) and [saved output](artifact-csv-check.json) preserve CSV SHA-256 `47b550fd7a4dfafb59a269e73f50ade96a9abd9484e32b17498581b4251eff48`. They add each row's separate summary cost without imputing missing values. On **the same fifty IDs** as N=43 hybrid, raw, masking and summary each also solve 28/50. Hybrid/raw and hybrid/summary have two wins and two losses each; hybrid/masking has three each. Thus the +2.6-point headline is not a matched accuracy gain in these released records. Equal aggregate counts are not equivalence, and this descriptive check does not reproduce the paper's inferential analysis.

Gemini costs are reported from Vertex usage; self-hosted Qwen costs are post-hoc Alibaba price estimates, not paid GPU cost. Qwen-32B uses identical cached/uncached input prices; Qwen-Coder uses context tiers. The inspected script prices summary records using the `cost_tier` left from the trajectory loop rather than recalculating each summary's context tier. Its impact depends on actual records and is unquantified. Table 2's $.0439 reported 7.20% share matches $.61, while division by the $.64 summary total is 6.86%. Price, cache, missingness and retry assumptions must remain explicit; historical prices are not current forecasts.

## ALF implication

Remove novelty for masking versus summarization/hybrid controls. Distinguish current diagnostic content, aged observations, reasoning/action history, task commitments and source state. Any future policy comparison must hold the same predecessor and visible commitments fixed, predefine cache/summary cost and paired denominators, retain failures, and test sensitivity without tuning on final outcomes. These results support a useful baseline to evaluate; they do not authorize deleting active feedback, building a new memory layer, or attributing package cost differences to architecture.
